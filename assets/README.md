# Ресурсы игры

Все исходные для сборки игровые ресурсы хранятся только здесь: images, sounds, fonts, spine, libs и server-images. Контрольные суммы — в manifest.json. Публичная копия создаётся автоматически при сборке; это результат, а не второй источник.

Каталог images/layers может содержать текстуры, на которые ссылаются скомпилированные игровые анимации. Удалять весь layers по названию нельзя. Авторские PSD/FLA, нарезки для редактирования и предпросмотры вынесены из проекта.

Проверка полноты: `npm run test:assets`. Изображения проверяются с точным регистром для совместимости Windows и Linux.
