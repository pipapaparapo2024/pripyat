# Графические материалы

`source/` содержит редактируемые исходники и авторские экспорты. Они не публикуются автоматически вместе с игрой.

Готовые изображения игры находятся в `../_client/development/images/`. Этот каталог повторяет относительные пути серверной папки `client/ver0_41/development/images/`; менять имена внутри него без обновления загрузчиков нельзя.

В рабочей области `stalker.code-workspace` готовые изображения и исходники доступны отдельными разделами. Не нужно искать их среди кода или архивов.

`source/img/import_to_animate.jsfl` теперь вычисляет пути слоёв относительно собственного расположения, без привязки к прежней папке img в корне проекта.
