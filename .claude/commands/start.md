# Скилл: start — брифинг в начале сессии

Выполни все шаги сам, без вопросов. Запускается командой `/start`.

## Шаги:

1. **Версия** — прочитать из файла:
```bash
grep -o 'v=[0-9]*' _client/development/index.html
```

2. **Недавно изменённые файлы** — что трогали последним:
```bash
find _client/src -name "*.js" -newer _client/development/index.html | head -10
```

3. **TODO** — показать если есть:
```bash
cat TODO.md 2>/dev/null || echo "TODO.md не найден"
```

4. **Итог одним блоком:**
```
📦 Версия: v=XXX
📝 Изменённые файлы: [список]
✅ TODO: [список задач или "пусто"]
```

Никаких вопросов, никакого лишнего текста — только итоговый блок.
