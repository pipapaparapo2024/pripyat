# Проверки исправлений 30.10.2026

Запуск: `node tests/run-session-regressions.js`. Нужен локальный PHP.
Раннер не подключается к серверам, не применяет миграции и не выполняет деплой.

| Исправление | Поведенческая проверка |
|---|---|
| Авторизация и смена ключа | `security-oct30-regression.test.js`: неверный токен/ключ, повтор запроса, срок параметров запуска, поддельная подпись |
| Атомарная смена ключа | `security-request-key.test.js`: настоящий `Database.rotateRequestKey`, параметры запроса, отказ чужому UID, истёкшая сессия, два запроса с одним ключом |
| Выпуск токена | `security-request-key.test.js`: подписанный UID не совпадает с POST UID; легитимный вход сохраняет случайный токен и совместимый ключ |
| SQL-значения | `security-oct30-regression.test.js`: настоящий `toSQL`, кавычки, обратные кавычки, кириллица, запрет поддельного имени колонки |
| «Натиск» | `security-oct30-regression.test.js`: старый метод отказывает до доступа к БД; `users-php-real-exec-save-whitelist-holes-closed.test.js`: поддельные попытки/убийства не попадают в запись, обычное сохранение работает |
| Отладочная энергия | `security-request-key.test.js`: исполнение файла возвращает HTTP 410 и JSON `gone` без подключения к БД |
| Баннеры ОК | `ok-banner-viewport.test.js`: резерв, геометрия, поворот и координаты кликов, отсутствие изменений метрик VK |
| Кнопки правого меню | `right-menu-daily-hitarea.test.js`: настоящие методы панели и `touchPad`, раздельные клики и hover для мыши/тача |
| Миграция базы ОК | `ok-feature-schema.test.js`: диагностика без изменений, добавление девяти полей, повторный запуск, запрет базы VK, отсутствие изменения данных, освобождение блокировки при ошибке |

Дополнительно раннер включает основные 97 проверок, существующие тесты 2048,
Разнарядки, заначек, определения площадки, оплаты и поворота экрана.

Границы покрытия: PHP исполняется локально, MySQL-подключения заменены тестовыми
объектами. Это не нагрузочный тест конкурентных MySQL-соединений и не визуальная
проверка игры внутри настоящей оболочки ОК. Для баннеров проверяется геометрия
зарезервированной области, а не поведение внешнего рекламного SDK.
