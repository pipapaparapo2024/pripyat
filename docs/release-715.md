на проде был уже включён, сервер не требует Dev-прав для старта. Рейтинг считает
только завершённые партии. Сама иконка входа не имела отдельного затемнения.

его offsetSet не перезаписывает существующие ненулевые значения. База получала
новый ключ, а ответ содержал прежний. Исправлено явным unset/set одного transient
поля; тест расширен Registry с тем же контрактом и двумя последовательными запросами.
