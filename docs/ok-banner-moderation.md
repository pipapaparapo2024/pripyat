# Баннеры ОК и доступность кнопок

В `index.js.resize()` размер игры ранее вычислялся только из размера iframe и
системных safe-area. Баннер родительской оболочки ОК находится вне DOM игры и не
обязан уменьшать iframe. Он перекрывал правое меню, включая после скрытия объявления.

`modules/ok-banner-viewport.js` резервирует пространство перед масштабированием
всего canvas. Используется только `isOk()`; ветка VK получает исходный прямоугольник.
Логические координаты и обработка поворота/кликов остаются прежними.

Без сведений о настройках автопоказа резерв консервативный: сверху/снизу 114 CSS px,
на компьютере по бокам 328 px, на мобильном в альбомной ориентации по 128 px.
На портретном мобильном боковые отступы не нужны по таблице поддерживаемых форматов.
Из-за резерва игра в ОК отображается меньше даже при отсутствии рекламы. Миниатюрные
окна, в которых реклама занимает весь экран, не обеспечивают пригодного для игры места.

Перед повторной модерацией нужно проверить автопоказ в кабинете ОК. Предпочтительны
`bar_outer`, `thin_outer`, `vertical_outer`: они сдвигают контейнер игры вместо наложения.
При автопоказе рекламные методы SDK запрещены; код не пытается скрывать рекламу или
переинициализировать FAPI, чтобы не затронуть платежи/оболочку ОК.

Источники:
- https://new.apiok.ru/apps/features/banner_ads
- https://new.apiok.ru/en/dev/sdk/js/ui.getBannerFormats

Локальная проверка: `node tests/ok-banner-viewport.test.js`, тесты viewport/поворота,
сборка webpack. Проверка внутри настоящей оболочки ОК перед новой заявкой обязательна:
экран с баннером, скрытым баннером, поворот телефона, выход из попапов и покупка валюты.
Размещение кода и изменение кабинета этой правкой не выполняются.
