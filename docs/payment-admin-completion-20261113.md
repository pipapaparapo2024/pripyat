# Пакет оплат и административного входа — 13.11.2026

## Проверенные изменения

TOTP: Base32 с дополнением последнего блока; state читается до проверки сессии; сессия связана с отпечатком секрета. Ошибки state закрывают доступ. После неверных кодов задержка растёт до пяти минут. Enrollment показывает ключ только после Basic Auth. Секрет не выводится CLI-командой provisioning.

Сверка: постраничный проход по ID без голодания старых заказов; отдельная блокировка процесса на мир; started/result в закрытом файловом журнале. Данные игроков меняет только штатный settle после API-подтверждения. Миграций нет.

История: последние доступные записи сверки для платежа, с ограничением чтения и числа строк. Это не полный бессрочный архив. Отсутствие записей не означает отсутствие попыток.

## Подготовка TOTP

`php tools/rewards-totp-state.php /закрытый/путь/state.json admin` создаёт новый файл исключительно через режим x. Права выдавать только двум административным FPM-пользователям через отдельную группу. Добавить путь в open_basedir и PRIPYAT_REWARDS_TOTP_STATE обоих пулов. До включения gate проверить enrollment через FPM.

Владелец самостоятельно переносит ключ с HTTPS-страницы под Basic Auth в Google Authenticator и подтверждает код. Автоматические тесты не заменяют эту привязку.

## Восстановление доступа

Выполняет только администратор VPS по SSH. Сохранить старый state в закрытом каталоге root 0700; не печатать секрет. Создать новый state утилитой, восстановить ограниченные группу и права 0660. При необходимости сначала отозвать Basic Auth. Замена секрета отзывает старые TOTP-сессии. Gate не отключать. Проверить вход владельца и удалить старый секрет согласно срокам хранения. Никогда не включать секрет в Git, URL или журнал.
