# Единый релиз v726

- Разнарядка использует два предоставленных PNG: raznaryadka-button.png и raznaryadka-button-hover.png. Оба выводятся строго 236×57 с alpha=1; визуальная прозрачность определяется самими файлами. Оба ассета включены в прелоад.
- На прод переносятся все серверные исходники и конфигурации текущего main, включая ранее отсутствовавшие хуки прогресса Разнарядки и выдачи карточек коллекций в Зоне, рулетке, покере и ящике.
- При переносе хуков проверена их совместимость с защитой энергии: повторное чтение игрока внутри учёта ежедневного задания не должно скрывать списание энергии из итогового ответа клиенту. Это покрыто отдельным регрессионным сценарием.
- Устаревший сборный _bigger.json пересобран из donuts.json согласно штатному _bigger.php; посторонний старый каталог другой версии игры в нём не сохраняется.
- Тест первым собирается из зафиксированного GitHub-коммита. После его проверки тот же снимок публикуется на прод. Все публикуемые PHP/JSON, JS/HTML и новые ассеты сверяются SHA256 между GitHub-снимком, тестом и продом.
- registry.php не публикуется. Базы, ключи приложений и данные игроков остаются отдельными. Миграции и сбросы данных не запускаются.

Самостоятельный тестовый деплой: deploy-test.cmd. Синхронизация прода с уже проверенным тестовым GitHub-снимком: tools/sync-prod-from-github.py --apply. Сначала исходники отправляются в main; затем запускается тестовый деплой, после него — продовый.
