# Перенос на ноутбук

Переносится весь Git-проект с папкой assets, без node_modules, .deploy_deps, .venv и генерируемых копий ресурсов. Архивы прежних релизов, Photoshop/Animate и выгрузки логов не нужны.

После клонирования: `npm --prefix _client ci`, затем `npm run build` и `npm test`. Сборка создаёт публичные копии из assets. Нужны Node.js/npm; для полного набора серверных тестов — PHP с mysqli. Инструменты Python используют tools/requirements.txt.

Для собственной локальной БД есть `database/schema.sql`: только структура, без данных игроков. Создайте отдельную пустую базу и собственный приватный registry.php по registry.example.php. Схему нельзя автоматически импортировать в PROD/TEST; в текущей работе она нигде не применялась.

Файлы настроек и SSH-ключи передаются отдельно и никогда не добавляются в Git. Базы разных окружений не синхронизируются вместе с кодом. Вход в игру требует корректной платформенной авторизации; локальная сборка не отключает её.
