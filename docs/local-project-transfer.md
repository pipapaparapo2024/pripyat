# Перенос проекта на другой компьютер

Сервера содержат установленную игру, а не полный проект разработки. `/var/www/stalker` — PROD, `/var/www/stalker-test` — TEST. Эти каталоги можно скачать через SFTP (например, WinSCP) или scp. Копирование файлов не изменяет сервер.

Для разработки нужны исходники `_client/src`, конфигурация сборки, `server`, тесты, инструменты, документация и полные локальные игровые ассеты. Они должны соответствовать одному релизу. Минифицированный серверный `libs/index.js` не заменяет исходники клиента.

Предпочтительно переносить подготовленную локальную рабочую копию, исключив `node_modules`, `.deploy_deps`, локальные архивы релизов и логи. Зависимости устанавливаются отдельно. Секреты и registry.php нельзя добавлять в Git или передавать в общедоступном архиве. Для локального запуска PHP требуется отдельная конфигурация и отдельная база; нельзя использовать настройки подключения к PROD.

База MySQL не входит в папку сайта. Её перенос — отдельный экспорт; реальные данные игроков не нужны для работы с графикой и сборкой клиента.

После реорганизации обнаружены отсутствующие авторские исходники, на которые ссылаются старые Adobe-инструменты:

- `assets/source/img/psd/ящик.psd`
- `assets/source/img/psd/худ3,0.psd`
- `assets/source/img/psd/Компас.psd`
- `assets/source/content/animate/interface_elements/interface_elements.fla`

Это не изображения, загружаемые игрой: готовые экспорты существуют отдельно. Эти четыре исходника нужно найти в авторском архиве; скачивание работающего сайта не гарантирует их восстановления.
