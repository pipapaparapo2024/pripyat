# Разбор VK TEST 03.11.2026

## Причины сообщений пользователя

- Семь 404 файлов рангов: декоративная анимация dvor-blackjack.js запрашивала `./images/восьмерка.png` и аналогичные имена без префикса «карта ранг ». Исправлено обращение к существующим ресурсам, механика и награды не меняются. Исполняемый тест перебирает все восемь случайных рангов и проверяет наличие исходных файлов.
- Подробные console-сообщения: TEST-домен включал debug_mode всем. Новый ранний фильтр пропускает диагностику VK только числовому ID 382448269. Остальные VK ID и OK не получают сообщения игры; роль разработчика Telegram остаётся отдельной. Фильтр не предоставляет серверных прав и не скрывает сообщения браузера/внешнего родительского iframe VK. Дополнительные debug-tools остаются ограничены TEST-доменом.
- Bank больше не печатает полный подписанный launch. Из сообщений об отказе удалены недоказанные выводы по длительности запроса и перечень предполагаемых причин.
- В период попыток пользователя 21:41–21:42 МСК подписанные запросы к TEST callback были отклонены с reason=test_notifications_only. Пользователь подтвердил зависание «Ожидание информации о товаре», после закрытия которого SDK сообщал User denied. Это не подтверждение добровольного отказа от уже готовой покупки.
- Причина зависания каталога исправлена разделением операций: подписанные get_item/get_item_test возвращают только сведения о товаре без обращения к БД. Название товара помечено [TEST]. Начисление принимает исключительно order_status_change_test; обычный order_status_change отклоняется ещё до SQL, дополнительный guard есть внутри credit(). Пометка [TEST] — название нашего товара, она сама не доказывает тестовый режим окна ВК. Реальную оплату не включать без отдельного решения.
- apptracer/tns-counter/stats.vk-portal/ad.mail.ru — сторонние запросы окружения VK. Их ошибки не исправляются подменой console внутри игры.
