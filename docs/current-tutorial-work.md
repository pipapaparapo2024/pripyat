Реализовано:
- На восьми вкладках — исходный попап Седого, транскрипт соответствующей реплики, блокировка на время озвучки, закрытие по окончании. При выключенном/неисправном звуке — Продолжить.
- В Зоне: Кордон, одно действие с энергией, выход из локации и выход из списка. Повторный клик во время запроса блокируется. Уже завершённый Кордон и недостаток энергии объясняются без зависания.
- База: первая страница, один переход вправо, выход. Остальные вкладки: объяснение, выход.
- Рука, пульсация и hit area следуют объекту целевой кнопки через getBounds/toLocal. Правило добавлено в AGENTS.md.
- Во Дворе мигают четыре игровых облака, три облака сухарей и 2048; учитывается отложенная загрузка Двора.
- Тексты валюты, финала, разрешения и подтверждения/завершения выхода берутся из переданных txt.
- Буфер canvas после начального выделения остаётся постоянным; жест меняет плотность текстур шрифта, без повторного renderer.resize. Ввод синхронизирован с фактическим разрешением буфера.
- Изображения получают ключ текущего входа и повторно используются внутри сессии.
- 2048: ПК — клавиши; мобильные — свайпы с поля, отмена касания и мультитач не делают ход, обработчики снимаются при закрытии.
