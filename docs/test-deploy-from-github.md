# Самостоятельный деплой на тест

Открой PowerShell в `C:\Users\HONOR\Desktop\vk_game\projects_2026\pripat` и выполни:

```powershell
.\deploy-test.cmd
```

Команда получает `main` из GitHub, извлекает отдельную копию выбранного коммита, собирает webpack, запускает проверки энергии/заначек/аватаров/попапов/кнопок и обновляет только `/var/www/stalker-test`. Локальные незакоммиченные изменения в игру не попадут.

Необходимы уже настроенные GitHub-доступ, Node.js, зависимости `_client/node_modules`, Python среды Codex, `.deploy_deps` и SSH-ключ `~/.ssh/id_ed25519_stalker`. Это готовая команда для этой рабочей машины.

Скрипт не загружает `registry.php`, не запускает миграции, не очищает базы. Настройки БД и VK-приложения теста остаются собственными. До замены файлов делается резервная копия, проверяются хеши и PHP-синтаксис. При изменении PHP перезапускается PHP-FPM.

Для публикации своих изменений сначала отправь нужные исходники в `main` GitHub. При новом релизе обнови номер `index.js?v=...` в `_client/development/index.html`. После успешного деплоя полностью перезагрузи тестовую игру.

Режим плана без публикации: запусти `tools/deploy-test-from-github.py` без `--apply` тем же Python. Он получает исходники, собирает и проверяет их, затем показывает список отличий на сервере.
