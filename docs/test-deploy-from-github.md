# Публикация на TEST

Из корня проекта:

- `npm --prefix _client ci` — установка зависимостей сборки.
- `npm run build` — сборка и копирование ассетов.
- `npm test` — основные и регрессионные проверки.
- `python -m pip install -r tools/requirements.txt` — зависимости обслуживания.

`deploy-test.cmd` получает main из GitHub и публикует только TEST. Незакоммиченные локальные изменения в него не входят. Нужен настроенный SSH-ключ `~/.ssh/id_ed25519_stalker` и собственный доступ к репозиторию.

Для проверки локальной рабочей копии до отправки в GitHub: `python tools/deploy-local-test.py` показывает план, `python tools/deploy-local-test.py --apply` публикует на TEST. Этот инструмент проверяет манифест, создаёт резервные копии и переносит лишние статические файлы теста в закрытый архив. В PROD не пишет, базы не меняет.

После публикации: `python tools/smoke-test.py`. Проверяется отдельный синтетический аккаунт TEST. Не запускайте автоматически миграции или очистку данных игроков.

В новой папке при установленном виртуальном окружении запускайте Python из него. Приватные registry.php никогда не загружаются вместе с релизом.
