# Локальная копия при работе над проектом

По просьбе владельца от 06.11.2026 автоматическое скачивание в Windows отключено. Серверный бэкап остаётся ежедневным в 00:00 Europe/Moscow. MD-файл не запускается при открытии приложения ChatGPT: это инструкция агенту, работающему с данным проектом.

В начале работы в новом чате проекта проверить только дату и наличие локального manifest:

`C:/Users/HONOR/.pripyat-backups/daily/latest.json`

Не выводить содержимое SQL, приватные данные, токены и журнал удалений. Если manifest отсутствует, копия неполная или timestamp старше 24 часов, один раз сообщить: «Локальная резервная копия старше суток [либо отсутствует]. Обновить её сейчас?» Не повторять вопрос в каждом сообщении. Если пользователь уже поручил обновить копию в текущем чате — выполнить без повторного подтверждения.

Команда после согласия:

```powershell
python "$env:USERPROFILE/.pripyat-backups/pull-database-backups.py"
```

Скрипт скачивает последнюю готовую серверную копию, а не создаёт новый снимок текущего состояния. Для свежего снимка перед изменениями отдельно запустить `systemctl start pripyat-platform-backup.service` на новом VPS и затем скачать. Создание копии разрешено в рамках поручения на резервирование. Старый Beget VPS не использовать.

Скрипт проверяет 7 SQL gzip + независимый журнал удалений: SHA256, размер, целостность gzip. Обновляет актуальный журнал удалений отдельно. Локальные суточные копии и известные исторические копии в `Desktop/vk_game/projects_2026/db_backups/new-server-20261103` очищаются по сроку 30 дней при запуске скрипта. Если компьютер/скрипт долго не запускается, физическая очистка локальных файлов откладывается; не обещать безусловное удаление на 30-й день. Не использовать просроченные архивы для восстановления.

Папка `.pripyat-backups` ограничена ACL текущим пользователем и SYSTEM. Это отдельная от VPS копия, но не круглосуточное внешнее резервирование. Вне этого проекта и без чтения AGENTS.md напоминание не гарантируется.

При восстановлении сначала прочитать `docs/privacy-operations-20261106.md`. Никогда не открывать восстановленную игру до импорта актуального журнала удалений и повторного удаления отмеченных аккаунтов.
