# Релиз 724: только прод

Продовая сборка основана на v723, без тестовой диагностики, сравнения текстур и изменения разрешения canvas.

- Тренировка на базе не списывает энергию, не сбрасывает её таймер и доступна с нулевым балансом. Бот не требует энергию для тренировки.
- Автосохранение клиента не пишет energy/energy_time/stash_data. Неизменённые снимки энергии и заначек не перезаписывают новые серверные значения при сохранении других действий. Ответы таких действий не откатывают энергию в HUD.
- Энергия расходуется при заполнении чекпоинта Зоны; восстановление со временем сохранено. Существующие покупки и награды энергии не отменяются.
- Попап просьб друга вложен в его профиль. Закрытие поглощает событие, общий крестик сначала закрывает попап, затем профиль. Ответы после закрытия профиля игнорируются.
- Не больше 10 успешных отправок одному получателю за московские сутки. Отправитель, получатель и квота сохраняются одной транзакцией. Метаданные квоты хранятся в server-only stash_claims._gifts, без новых столбцов.
- stash_claims[1..15] теперь содержит число обменов коллекции; старое true читается как один подтверждённый обмен. Историческое число повторных обменов ранее не сохранялось и не выдумывается.
- 30 достижений восстановлены в клиентском каталоге. Серверный каталог уже содержал их. Прогресс берётся из количества обменов, не количества отдельных карточек. Порядок 15 коллекций соответствует порядку старых ключей Кордон/Свалка/Тёмная долина/Агропром/Янтарь.
- У топ-1 2048 аватарка не добавляется на сцену. Аватары остальных мест сохранены.
- Разнарядка: одна новая текстура, alpha 0.8 / 1 при наведении, без ColorMatrixFilter.

Проверки: все 708 файлов общего прогона прошли; добавленный 709-й тест отдельно исполняет настоящие PHP-контроллеры передачи/обмена на фейковом транспорте и проверяет откат при сбое записи получателя. Набор проверок сессии: 24 пункта, включая штатные 97 проверок run_tests.js.

База не мигрируется, данные игроков не сбрасываются. Тестовый сервер остаётся на v721.
