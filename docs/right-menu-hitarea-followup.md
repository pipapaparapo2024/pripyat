# Повторная проверка правого меню

Повторный репорт после v715: наведение/нажатие на другие вкладки открывает задания.
Предыдущая правка убрала большой сдвиг Graphics, но оставила общий `touchPad(72)`
для кнопки высотой 57 с промежутком 4. Расширение на 7.5px сверху пересекает край
предыдущей кнопки. Это воспроизводится настоящим `PIXI.InteractionManager.hitTest`.

На текущем v715 тест подтверждает перехват нижнего края Сводки; центр Двора уже
не перекрывается. Поведение старого кода (до v715) включало большой сдвиг hitArea
вверх к Двору. Версия вкладки игрока из одного текстового репорта неизвестна;
нельзя утверждать, что повторный случай Двора объясняется только малым padding.

Исправление: все пять Graphics рисуются в локальном (0,0), смещается сам объект,
на каждом задан явный hitArea 236×57. Generic touchPad для этой плотной группы
не применяется, промежутки между кнопками остаются некликабельными.

`tests/right-menu-native-pixi-hitarea.test.js` исполняет настоящую bundled PixiJS
6.5.10 и методы панели, а не собственную модель попадания. Проверяет все 5 кнопок,
по 9 точек на каждой, промежутки, три масштаба, desktop/touch и hover. До правки
падает на неверной цели `raznaryadka` вместо `svod`. Старый mock-тест этого края
не проверял и не заменял проверку фактической библиотеки.
