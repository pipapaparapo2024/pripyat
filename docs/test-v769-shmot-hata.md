# Исправления TEST: экипировка и локации, 03.11.2026

## Причины

Проверка живого сервера подтвердила: shmot.php совпадал с локальной версией, то есть серверные исправления надевания не были потеряны. Новый gateway при переносе сервера запрещал все dev/reset-методы, в том числе users.devGrantShmot. Клиент при этом оптимистично выставлял owned=true ещё до HTTP-ответа. Сервер возвращал 403; неподтверждённые вещи были видны только в памяти, equip закономерно отклонял их, перезапуск убирал их.

Изображения «хата фон станция.png» и «хата фон заправка.png» визуально проверены: сейчас в первом железнодорожная станция, во втором АЗС. Старый фикс HATAS сохранял противоположные названия под прежнее содержание артов. Серверный каталог и главная сцена имели правильные ID/порядок файлов. В HATAS восстановлено: id6 Станция, id7 Заправка. Цены, условия открытия, сохранённые ID и сами арты не меняются.

## Изменения

- TEST gateway делает точное исключение только для users.devGrantShmot. Подпись, сессия и серверный _requireDevUser обязательны; остальные dev/reset-операции не открыты.
- Dev-панель не меняет владение до успеха. После подтверждённого patch перечитывает предметы и обновляет магазин. Повторный клик во время запроса заблокирован; отказ не создаёт ложных предметов.
- Названия локаций сверяются тестом с серверным каталогом вместе с ценами и требованиями.
- По отдельному подтверждению пользователя иконки штанов id103/id113 обрезаются только в магазине: 85 px сверху и 15 px снизу от отображения высотой 185 px, итог 85 px. Общие PNG и изображения на персонаже не меняются. Обрезка работает и при отложенной загрузке текстуры.
- На сайте заголовок заменён на «Зона ждёт. Играй и добивайся успеха.» Только index.html, без авторизации/конфигов. Проверен в Edge на ширине 1280/390: текст актуален, горизонтального переполнения нет.
