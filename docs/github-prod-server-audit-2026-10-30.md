# Сверка GitHub и прода после деплоя теста

Статус: выявленные ниже различия включены в единый релиз v726. Это историческая запись о состоянии до синхронизации.

GitHub main: 95c9010, клиент v725. Его сборка совпадает с JS прода и теста: SHA256 `90fa7f89b6cc8b0676dd2ff4125b47470af5bcb68a50a377c89fed630c43e255`.

Сервер не является полной копией GitHub. При проверке 75 PHP/JSON-путей без registry найдено:

- 12 контроллеров с отличиями логики: bp, dice, dvor, habar, poker, roulette, ryukzak, tasks, vassilich, yashik, zaruba, zone. В частности, GitHub содержит хуки прогресса Разнарядки и выдачи карточек, отсутствующие в части продовых контроллеров.
- Различаются errors.json и старый сборный _bigger.json.
- На проде отсутствуют base_buildings.json, base_stats.json, bp_rewards.json, gangs_defs.json, присутствующие в GitHub.

По просьбе пользователя тест развёрнут именно из GitHub, включая эти серверные исходники. Прод при этой операции не обновлялся. Registry теста побайтово сохранён, миграции и сбросы данных не выполнялись. Изменения сервера нельзя автоматически считать уже выложенными на прод только по номеру клиентской версии.

Копии для чтения и сравнения сохранены локально в игнорируемой папке `_client/development/prod-server-audit/`. Никаких секретов registry туда не копировали.
