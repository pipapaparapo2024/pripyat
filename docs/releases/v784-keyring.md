# Стабильная версия v784-keyring

Серверное обновление от 7 ноября 2026 года поверх исправления джекпота и Разнарядки. Сборка клиента остаётся v784.

- Колесо и стаканчики проверяют общий таймер под блокировкой. Награда, расход поинта или выбранного стаканчика и таймер сохраняются в одной транзакции.
- Если связку уже получил другой игрок, старый стаканчик даёт 1000 опыта один раз. Ошибка записи оставляет попытку доступной для повтора. Принудительная выдача из Dev-панели не запускает общую паузу.
- Условия джекпота и вероятности выпадения сохранены.

Проверены 97 базовых проверок, 795 тестовых файлов и отдельный сценарий MySQL на временных таблицах с принудительной ошибкой записи. Серверная версия опубликована на сайте, в ВК/ОК PROD и TEST и Telegram TEST.

Закрытые снимки до и после публикации на VPS:
- `/var/backups/pripyat-v784-keyring-test-20261107T112348Z`
- `/var/backups/pripyat-v784-keyring-prod-20261107T112349Z`

Для отката этого обновления используйте файл из каталога `before` соответствующей площадки. Точный проверенный файл релиза находится в `working`. Контрольные суммы указаны в `manifest.json`. Откат серверного файла не требует отката БД.
