# v785 — стаканчики, бой с боссом и восстановление входа по наградной ссылке

Дата публикации: 07.11.2026.

## Изменения

- Если глобальная связка уже занята, открытый стаканчик выдаёт один обычный случайный приз из существующего пула. Отдельная компенсация 1000 опыта удалена. Пустой слот не выдаёт повторную награду; транзакция сохраняет приз вместе с закрытием стаканчиков. Положительный порог джекпота и атомарная выдача связки сохранены.
- Бой с боссом сохраняет сложность отправленной атаки и игнорирует устаревший ответ опроса HP. Общий путь покрыт для восьми боссов и четырёх сложностей.
- Аватары трёх лидеров урона имеют размер 40×40 и координаты X29, Y528/589/652, включая асинхронную замену текстуры.
- Личный сброс через Dev-панель обнуляет очки казино, фишки, очки навыков и клиентский кэш достижений. Данные других игроков не сбрасывались.
- Вход с наградной ссылки сохраняет код и площадку при переходе к выбору способа входа. Чужая активная площадка требует выбора правильного входа. Награды вручную не начислялись.
