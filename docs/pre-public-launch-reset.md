# Очистка перед публичным запуском

04.11.2026 пользователь потребовал перед открытием всем игрокам очистить игровые PROD-БД ВК, ОК, Telegram и самостоятельных аккаунтов сайта, чтобы тестовые персонажи/рейтинги разработчиков не попали в публичный запуск. Это отложенный этап выпуска. Сейчас никаких очисток, DROP/TRUNCATE и миграций не выполнялось.

Перед исполнением:

1. Закрыть игровые входы и сохранения всех четырёх миров, временно отключить новые покупки. Проверить ожидающие платежи и окончательные статусы: сейчас есть репорт ожидающего подтверждения платежа ВК. Не удалять данные, необходимые для его подтверждения/возврата.
2. Сверить точные PROD имена БД и настройки доменов, отдельно от TEST. Для текущих ВК/ОК: stalker и stalker_ok. Telegram и сайт определить по фактическим приватным конфигурациям к моменту запуска; не угадывать имена.
3. Сделать закрытые резервные копии, проверить восстановление. Историю реальных платежей, подтверждений, возвратов и обязательств сохранить в защищённом архиве с возможностью сверки поздних callback. Секреты и дампы не публиковать в GitHub.
4. Подготовить проверяемый список очищаемых игровых/сессионных данных и необходимых служебных строк, без переноса тестового прогресса. Не сбрасывать каталоги/конфигурации/ключи и не создавать пользователей SQL с избыточными правами. Порядок сброса и обработку поздних оплат отдельно проверить перед исполнением.
5. После очистки проверить пустые рейтинги, отсутствие тестовых персонажей, новый вход, создание персонажа, сохранение, изоляцию четырёх миров и защиту повторной оплаты. Только затем открыть публичный доступ.

Не использовать этот файл как команду выполнить очистку прямо сейчас. Выполнять на финальном этапе публичного релиза после проверки состава и резервных копий.

Перед публичным запуском обязательно выключить payments.vk_developer_sandbox, закрыть ожидающие тестовые заказы и архивировать отрицательные tid отдельно от настоящих положительных. Сейчас режим включён только на закрытом native PROD v774 для допущенных разработчиков.
