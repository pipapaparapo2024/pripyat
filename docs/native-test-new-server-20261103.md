## Ручная приёмка

В настройках TEST приложения ВК должен быть URL `https://test-pripyat-game.ru/client/ver0_41/index.html`. Если запуск ещё направлен на основной домен, игра не попадёт на этот TEST автоматически. Не менять адрес существующего PROD-приложения без отдельного согласования. Уточнить у пользователя ссылку/ID TEST-приложения и соответствие native-секрета, если получен отказ подписи.

Проверить в настоящих ВК и ОК: старт/обучение; имя/фото; смена ника/громкости и перезапуск; несколько действий с ресурсами; инвентарь/босс/ежедневные задания; доступные списки друзей; наградная ссылка дважды; магазин показывает отключённую оплату и не открывает списание. Прогресс ВК и ОК должен быть независимым. Подтверждать реальные оплаты на данном TEST не нужно.

Открытие прямого URL без подписанного запуска не является входом в игру. Сайт с OAuth VK/OK пока отдельно не подключён: эта задача развернула нативные TEST-приложения, не объявляет готовым сайт.

После приёмки потребуется отдельное PROD-развёртывание, подключение своих БД, домена, callback и адресов запуска обеих площадок. Одно копирование файлов не гарантирует запуск обеих без этих настроек.
