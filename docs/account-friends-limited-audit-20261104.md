## Выполнено
- Удалена видимая кнопка повторного письма. Восстановление открывает отдельную форму email, вызывает существующий защищённый forgot/reset с одноразовым токеном; пароль не требуется для запроса восстановления, но нужен для обычного входа.
- Исправлено подтверждение почты уже существующего аккаунта с паролем: ссылка больше не создаёт site_pending. После подтверждения требуется вход с паролем. Для незавершённой регистрации без пароля сохранено создание пароля и затем подтверждение телефона.
- Компактная карточка, интервалы между кнопками, отдельная вторичная кнопка восстановления. Изображение остаётся CSS-фоном. В браузере при высоте720px вход/регистрация/восстановление имеют scrollHeight720, скрытия содержимого overflow:hidden нет. При очень маленьком окне прокрутка допустима для доступности полей.
- Заявки по игровому ID реализованы только для самостоятельного сайта и Telegram. Изоляция обеспечена серверным выбором PDO/БД; ВК/ОК не получили сайт-заявки. Получатель видит отправителя и может принять/отклонить. Подтверждённая дружба взаимная, у Telegram сохраняется canonical telegram_friendships.
- Собственный ID виден в окне. Повторная отправка pending идемпотентна; себе/несуществующему ID отказ; повтор после отклонения ограничен часом; до20 новых исходящих заявок за час. Только получатель принимает заявку; встречная pending закрывается при принятии. При ошибке все записи откатываются транзакцией.
- Старые link invitations отключены в HTTP bootstrap сайта, Telegram login и Telegram bot /start; invite API исключены из allowlist. Классы прежних кодов оставлены для исторических тестов, публичные пути больше не создают такую дружбу. Существующие связи не удалялись.
