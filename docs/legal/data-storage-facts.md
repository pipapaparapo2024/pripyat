Удаление: запрос направляется на semka_semichevskaya00@mail.ru с указанием площадки и игрового ID. Поддержка проверяет владельца по привязанной почте/социальному входу; знание ID, имени или скриншот не является достаточным основанием. Пароль или банковские секреты не запрашиваются. Администратор отзывает доступ и выполняет комплексное удаление регистрационных/телефонных/профильных/игровых данных и связанных записей выбранного мира. Учётная запись ВК/ОК у самой соцсети не удаляется. Платёжная история сохраняется отдельно; при необходимости для целостности учёта остаётся заблокированная служебная строка без исходных контактов. Незавершённые платежи разбираются до завершения удаления. Общий ориентир — выполнение в применимый законом срок, как правило, не позднее 30 дней при отсутствии иных законных оснований хранения.

Восстановление: до открытия восстановленного окружения объединяется актуальный независимый журнал удалений и повторно удаляются перечисленные аккаунты. Доступ по прежним ID из журнала блокируется сервером. При отсутствии актуального журнала нельзя обещать безопасное восстановление: окружение остаётся закрытым до сверки обращений. Старые SQL-архивы не редактируются для выборочного удаления, а выводятся из обращения и очищаются по ротации.

Серверное резервирование ежедневно в 00:00 МСК. Копия на компьютер запускается вручную по поручению владельца. Правило проекта напоминает при начале работы, если локальная копия старше суток; открытие приложения ChatGPT само по себе не запускает MD-файл или копирование. Последний проверенный комплект содержит семь SQL gzip и независимый журнал удалений, проверяются SHA256/размер/gzip. Папка локальных копий ограничена Windows ACL владельцем и SYSTEM.

Внешние обработчики: Selectel (VPS и отправка почты), VK ID/ВК/ОК (авторизация), Zvonok (подтверждение телефона), ЮKassa (платежи; сейчас только допущенные тестовые операции). Их самостоятельные сроки/основания обработки не задаются нашими скриптами и должны быть отражены в полной политике отдельно.
