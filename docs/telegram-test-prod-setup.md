# Telegram TEST и PROD

Используем два уже существующих обычных бота. Специальная тестовая сеть Telegram не требуется. У обычного TEST-бота Stars настоящие: имя TEST не делает оплату бесплатной.

PROD: `@pripyat_game_bot`. По прямому указанию пользователя не запускать до успешной проверки TEST.

Каждый бот получает собственные токен, webhook secret, адрес приложения и БД. TEST не должен использовать БД PROD. Сейчас дополнительные тестовые базы не созданы; их создание требует отдельного согласования SQL.

Приватные файлы нового VPS:

- `/etc/pripyat/telegram-test-bot.json`
- `/etc/pripyat/telegram-prod-bot.json`

Подготовленные шаблоны выключены (`enabled: false`). Для заполнения через терминал:

```powershell
ssh -i "$env:USERPROFILE\.ssh\id_ed25519_stalker" root@135.106.159.212
```

На сервере:

```sh
nano /etc/pripyat/telegram-test-bot.json
```

Заполнить `bot_username` без @ и `bot_token`. Сохранить Ctrl+O, Enter, выйти Ctrl+X. Затем аналогично заполнить `/etc/pripyat/telegram-prod-bot.json`. Остальные поля, особенно `enabled` и `webhook_secret`, оставить без изменений. Не отправлять токены в чат и не помещать их в публичную папку сайта.

Заполнение файла само по себе не включает бота: затем нужны проверка getMe, раздельная конфигурация игрового API и проверка webhook. PROD включается после проверки TEST. Приватные файлы предназначены для последующего подключения; действующая игра пока их не читает.
