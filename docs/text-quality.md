# Чёткость текста

PixiJS 6 автоматически снижает разрешение PIXI.Text до renderer.resolution при отрисовке. Поэтому общий PIXI.settings.RESOLUTION не гарантировал плотность текста и не обновлял уже созданные надписи при зуме.

text-quality.js задаёт разрешение через публичный setter PIXI.Text непосредственно перед отрисовкой: учитывает плотность рендера, мировой масштаб (в том числе поворот), запас для сглаживания и ограничение памяти 4. При загрузке шрифтов сбрасываются метрики и уже созданный текст перерисовывается. На стабильном кадре повторной растеризации нет. Порог пересчёта canvas при зуме уменьшен до 0.001.

Размеры и координаты сцены не менялись. Это исправление относится к живому тексту PIXI.Text. Буквы, нарисованные внутри PNG, остаются частью изображения и требуют отдельной оценки исходника/фильтрации.

Проверки: tests/text-quality.test.js использует настоящую PixiJS; проверены существующие объекты, зум, масштаб/поворот, готовность шрифтов, Canvas и ограничение памяти. Финальная визуальная проверка выполняется в тестовой игре.

В v729 буфер canvas привязан к округлённому количеству физических пикселей, включая pinch zoom. Нижняя граница resolution=1 и мёртвая зона изменения убраны: при 1000 CSS px и DPR 1.25 используется ширина 1250, а не 1280. autoDensity=false сохраняет ручные CSS-размеры; resolution интеракшна обновляется вместе с рендером.
