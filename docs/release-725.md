# Прод v725

Отличия от v724 ограничены четырьмя клиентскими исходниками: interface-panels.js, svod-zanachki.js, svod-zanachki-wishlist.js и новым stash-count-layout.js. Серверные файлы и тестовый сервер не обновлялись.

- Разнарядка: alpha 0.4 в обычном состоянии, 1 при наведении. Одна и та же текстура.
- Основная сетка: все 105 счётчиков имеют значение, включая 0. Позиция — центр карточки по X и нижняя плашка по Y, после готовности реальной текстуры 71×93. Старые компенсации заглушки 1×1 (+35 и +92) удалены.
- Запрос друга: ожидаются обе текстуры, карточки и кнопки; количество дополнительно поднято на 3px только в режиме друга. Положение не зависит от порядка загрузки и наличия картинки в кеше.
- У счётчиков убрана чёрная обводка 2px, утолщавшая чёрные символы на мелком кегле. Минимальная плотность текстовой текстуры — 2. В попапе добавлена перерисовка после загрузки Southbank LT.

Проверки: 710 файлов тестов, включая холодный/тёплый кеш, оба порядка загрузки текстур, 105 количеств с нулевыми значениями, неизменность hover-hitbox и подъём у друга на 3px. Сборка webpack успешна.

GitHub должен содержать исходники этой продовой сборки. Тестовые изменения index.js, диагностическая панель и сравнения mipmap в продовую ветку не включаются. Собранный JS и основной набор игровых ассетов остаются вне Git по правилам проекта; новый небольшой ассет кнопки и продовый HTML включены отдельно.
