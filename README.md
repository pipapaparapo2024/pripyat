# Припять

Откройте **stalker.code-workspace** в VS Code: код, игровые изображения, звук, исходники графики, тесты и документация показаны отдельными разделами.

## Где что находится

| Путь | Назначение |
|---|---|
| `_client/src/` | Исходный код клиента |
| `server/core/` | PHP-контроллеры и модели |
| `server/json/` | Игровые каталоги и настройки |
| `_client/development/images/` | Изображения, загружаемые игрой; относительные пути как на сервере |
| `_client/development/sounds/` | Звуки и озвучка |
| `_client/development/fonts/` | Шрифты |
| `_client/development/spine/` | Анимации Spine |
| `_client/development/libs/` | Собранный клиент и библиотеки движка |
| `assets/source/img/` | Авторские слои, PSD, FLA и предпросмотры |
| `assets/source/content/` | Исходные экспорты Adobe Animate и их ресурсы |
| `assets/source/references/` | Дополнительные графические материалы |
| `tests/` | Автоматические проверки |
| `tools/` | Актуальные инструменты сборки и публикации |
| `docs/` | Документация, спецификации и история |
| `archive/legacy-tools/` | Исторические инструменты, не для текущего деплоя |
| `archive/local/` | Приватные старые скрипты, журналы, заметки и резервные копии; исключены из Git |

Игровые картинки уже собраны в одном каталоге images. Исходники графики хранятся отдельно: смешивать PSD/слои и загружаемые игрой PNG нельзя. Существующие имена и вложенность игровых файлов сохранены, чтобы не нарушить ссылки в Animate, Spine и динамических загрузчиках. Папка development исторически содержит публичные файлы игры; это не только временная сборка, удалять её нельзя.

## Работа

- Сборка: из `_client` выполнить `npm run build`.
- Основные проверки: из корня выполнить `node run_tests.js`.
- Публикация на TEST из GitHub: `deploy-test.cmd`. Подробности: [инструкция](docs/test-deploy-from-github.md).
- Скрипт синхронизации PROD: `tools/sync-prod-from-github.py`; без `--apply` только проверка. Автоматически при сборке ничего не публикуется.

Изображения и зависимости пока не полностью представлены в Git. Существующая установка содержит необходимые локальные файлы; клона GitHub недостаточно для чистой установки. Реорганизация не меняет настройки окружений и данные игроков.

Карта выполненных переносов для отката: `archive/local/layout-migration.json`. Старые сценарии из archive могут содержать прежние пути и не предназначены для запуска.
