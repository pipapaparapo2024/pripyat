# Припять

Рабочую область открывайте через `stalker.code-workspace`.

| Каталог | Назначение |
|---|---|
| `_client/src` | Исходники игры |
| `assets` | Единственный источник всех локальных ресурсов игры |
| `server/core`, `server/json` | Серверная логика и каталоги |
| `tests` | Проверки актуального поведения и тестовые фикстуры |
| `tools` | Сборка, проверка и публикация |
| `docs` | Актуальные инструкции и техническое задание |

`assets/images`, `sounds`, `fonts`, `spine`, `libs` повторяют публичную структуру клиента; `assets/server-images` содержит платёжные иконки сервера. `assets/manifest.json` фиксирует контрольные суммы. Внутри images/layers остаются только отобранные игровые текстуры: название layers само по себе не означает ненужный авторский материал.

`_client/development` и `server/images` содержат результаты сборки. Их ресурсы генерируются из assets, вручную редактировать их не нужно. Архивы слоёв, PSD, предпросмотров, старых релизов и отдельной админки вынесены за пределы проекта.

## Подготовка на другом компьютере

1. Установить Node.js/npm и Python 3, а для полного набора серверных тестов — PHP с mysqli.
2. `npm --prefix _client ci`
3. Для инструментов публикации и обработки графики: `python -m pip install -r tools/requirements.txt`.
4. `npm run build`
5. `npm test`

Сборка не требует файлов из прежней папки на Desktop. Для деплоя нужны собственный SSH-доступ и Git. Боевые registry.php и данные игроков в репозиторий не входят; конфигурацию локального сервера создают отдельно по registry.example.php.

Публикация из GitHub на TEST: `deploy-test.cmd`. PROD публикуется отдельно и только по явной команде. Проверенная сборка v731 опубликована на TEST и PROD по явной команде пользователя 31.10.2026.

После намеренного изменения ассетов: `npm run assets:update`, затем `npm run assets:audit`, сборка и тесты. По явной команде пользователя 31.10.2026 v740 опубликована на TEST и PROD; проверены все 5922 файла выпуска. Актуальная передача проекта: `docs/CONTINUE_HERE.md`. Приватные конфигурации и базы окружений остаются раздельными.
